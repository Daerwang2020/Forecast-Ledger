# Forecast Ledger

**Forecast Ledger** is the public-facing name of TS-Repro. The Python package
and command remain `ts-repro` / `tsr` so existing scripts do not break.

> No leaderboard. No blame. Only a sealed, rerunnable record of what was run.

The name is deliberately about provenance rather than competition. A ledger
keeps the effective configuration, split definition, upstream revision,
checkpoint, predictions, metrics, and digests together. It makes a result easy
to inspect without turning a scientific comparison into a social ranking.

## Product language

- **Run card**: one model × dataset × protocol execution.
- **Ledger**: a directory of sealed run cards and comparison summaries.
- **Bridge**: the narrow adapter that calls an official model API or CLI.
- **Protocol**: the frozen data, split, horizon, normalization, and metric rules.
- **Evidence view**: the local interactive browser generated by `tsr visualize`.

The brand is a layer above the stable package name: imports stay
`ts_repro`, catalog paths stay under `ts_repro/catalog`, and the CLI stays
`tsr`.
