# Code of Conduct

Forecast Ledger is a research tool maintained for a welcoming, rigorous
community. Contributors are expected to be respectful, specific, and
collaborative, especially when discussing negative results or reproducibility
failures.

Harassment, discrimination, personal attacks, doxxing, and bad-faith reporting
are not acceptable. Maintainers may remove comments, close issues, or restrict
participation when these standards are violated.

For private concerns, use GitHub’s private vulnerability/reporting channel for
the repository rather than posting sensitive details in a public issue.
