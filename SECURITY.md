# Security policy

Please do not post credentials, private dataset paths, checkpoint tokens, or
unpublished data in an issue or pull request.

For a suspected vulnerability, use GitHub’s private security reporting channel
for [Forecast Ledger](https://github.com/Daerwang2020/Forecast-Ledger/security)
and include a minimal reproduction, affected revision, and impact. If private
reporting is unavailable, open a public issue with sensitive details removed.

The project intentionally runs local model commands. Review every
`repository_dir`, command, and environment variable in a model catalog before
execution.
